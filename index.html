PFE Thesis (Research Project)

Title: Automatic Detection of Voice Deepfakes by Deep Learning and Multimodal Acoustic Analysis

Supervisor: Pr. Abdellah AGRIMA

Period: 2024–2026 (Defense planned: June 2026)

Description: Developed AdvancedDeepfakeDetector — a multimodal architecture fusing Wav2Vec 2.0 embeddings with handcrafted acoustic features (MFCCs, Mel-spectrograms, spectral centroid, rolloff, bandwidth, zero-crossing rate). Wav2Vec 2.0 branch uses attention pooling with length-weighted mean pooling for variable-length audio; acoustic branch uses statistical pooling (mean, std, skew, kurtosis) over time. Optimized hyperparameters via Optuna (50+ trials), achieving EER = 0.47% (lr=4.17e-5, wd=2.16e-4, dropout=0.25, val_loss=0.0074) on ASVspoof 2019 LA. Implemented chunked 4-second inference with weighted aggregation for unlimited-duration audio. Built full evaluation pipeline: EER, AUC, Precision, Recall, F1, confusion matrix, FAR, FRR.
